## สิ่งที่แอปทำได้ตอนนี้ (v1)

- **ดวงวันนี้** — คำนวณจากผังมหาทักษาของวันเกิดจริง (ตำแหน่งดาววันนี้ในดวงคุณ) + คะแนน 4 ด้าน + สีมงคล/สีเลี่ยงเฉพาะตัว + do/don't + affirmation — deterministic: วันเดียวกันได้ผลเดิมเสมอ
- **ถามดวง (ห้องพี่หมอโอรา)** — โหมดตำรา (ฟรี ไม่ต้องมี key) และโหมด AI (Gemini free tier — พี่หมอถาม follow-up ก่อนทำนาย อ้างอิง FACTS ที่ engine คำนวณเท่านั้น)
- **ไพ่ทาโรต์** — เลือกเอง 3 ใบ (อดีต/ปัจจุบัน/แนวโน้ม) จาก Major Arcana 22 ใบ + AI ตีความเชื่อมโยงกับดวง
- **ศาสตร์ตัวเลข** — เลขชีวิตจากวันเกิด + วิเคราะห์เบอร์โทร (ผลรวม + คู่เลขท้าย)
- **Safety ในตัว** — คำวิกฤต→โหมดรับฟัง+สายด่วน 1323, เรื่องอ่อนไหว (หวย/โรค/ลงทุน)→ไม่ฟันธง, output filter กันคำต้องห้าม
- **Privacy** — ข้อมูลทั้งหมดอยู่ในเครื่องผู้ใช้ (localStorage) ไม่มี server ไม่มี tracking
- **Feedback loop** — ปุ่มแม่น/ไม่แม่นทุกคำทำนาย + Personalization Score

## โครงสร้าง

```
app/            ← ตัวแอป (static PWA — ไม่มี build, ไม่มี dependency)
tests/          ← smoke tests (34 ข้อ รวม verify ตำรามหาทักษา)
CLAUDE.md       ← กฎ codebase สำหรับ AI agents (อ่านอัตโนมัติทุก session)
AI-OPS-PLAYBOOK.md ← รูทีนบริหารด้วย AI: QA sweep, content audit, marketing, ลำดับฟีเจอร์ถัดไป
DEPLOY.md       ← ขึ้นออนไลน์ฟรี (GitHub Pages + Gemini free key)
01|02|03-*.md   ← แผนธุรกิจ/เทคนิคฉบับเต็ม (reference สำหรับวันที่พร้อมสเกล — kiosk อยู่ในนี้)
```

## หลักการที่ไม่ประนีประนอม

1. LLM ตีความอย่างเดียว — ตำราและการคำนวณอยู่ใน `knowledge.js`/`engine.js` (กัน hallucination)
2. ไม่ทำนายเรื่องความตาย โรคร้าย หวย หรือชี้นำการลงทุน — เรื่องลบต้องมาพร้อมทางออกเสมอ
3. เพื่อความบันเทิงและการสะท้อนตนเอง — disclaimer ทุกจุดสำคัญ
4. ต้นทุนคงที่ = 0 จนกว่าจะมีผู้ใช้จริงพิสูจน์ demand (ดูลำดับใน AI-OPS-PLAYBOOK.md)
